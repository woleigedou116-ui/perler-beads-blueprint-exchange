# 0.1.0 MVP 测试版

冻结日期：2026-06-09

冻结分支：`feature/mard-coco-mvp`

建议版本标记：`v0.1.0-mvp-test`

这个版本作为 MARD 到 COCO 拼豆图纸转换工具的 MVP 测试版。冻结后只修阻塞级问题，不继续加入新功能、重做 UI 或调整识别策略。

## MVP 范围

- 上传本地图纸图片并在本机完成识别。
- 将 MARD 色号转换为 COCO 色号。
- 按来源色号和目标色号分组校对待确认结果。
- 支持校对队列中的整组确认和整组候选修改。
- 支持右侧选中格的单格手动修正。
- 支持单格和框选区域标记为非拼豆。
- 支持 MARD 识别叠加视图和 COCO 重绘预览独立缩放、拖拽、定位。
- 支持隐藏 COCO 色号，查看更接近烫完效果的预览。
- 支持当前项目用色统计和色号表查看。
- 支持保存、重新打开 `.beadproject` 项目文件。
- 支持导出 CSV、干净图、叠加图和项目文件。

## 样例验收建议

发布前建议至少手动跑以下类型：

- 一张常规无水印图。
- 一张复杂但可识别的图。
- `恶魔狼_有水印` 类水印图。
- `小夜_有水印` 类水印图。

验收重点：

- 能完成识别并进入校对。
- 校对队列不会因大量重复项变得无法操作。
- 整组确认和整组修改行为一致。
- 隐藏色号预览仍保留颜色、选中格和非拼豆区域状态。
- 保存、重新打开和导出流程可用。

## 已知问题

- 大面积水印、低清、拍歪或花体数字仍可能产生较多校对项。
- 当前版本优先保证无水印和轻水印图纸的基础转换流程。
- 水印区域自动降噪、跳过或更精细的不确定性策略放入 MVP 后续版本。
- 当前仍是浏览器界面的本地工具，后续可演进为独立桌面软件界面。

## 冻结规则

MVP 测试版冻结后只接受：

- 启动失败、无法识别、无法保存、无法导出等阻塞问题。
- 明确的数据损坏或结果批量错误。
- 打包发布所需的最小修正。

暂不接受：

- 新识别策略。
- 新 UI 大改。
- 新导出格式。
- 新色号体系。
- 非阻塞体验优化。
