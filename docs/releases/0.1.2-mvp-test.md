# 0.1.2 MVP 测试版

发布日期：2026-06-22

版本标记：`v0.1.2-mvp-test`

这是 `v0.1.1-mvp-test` 之后的 MVP 测试版维护发布，主要收录前端预览体验修复、阶段性交接文档和最新打包产物。这个版本仍是本地浏览器界面的测试版，不是正式安装器。

## 主要变化

- 修复 COCO 重绘预览中选中格框形状异常的问题。
- 优化滚轮缩放后的预览状态提交，减少缩放后画面残留或模糊感。
- 补充阶段性交接文档，明确下一位 agent 的阅读顺序、项目结构、冗余文件判断和多 agent 文档定位。
- 保持 MVP 主流程不变：上传识别、MARD 到 COCO 转换、校对、标记非拼豆区域、保存项目和导出。

## 便携包

建议上传到 GitHub Release 的文件：

```text
perler-beads-blueprint-exchange-v0.1.2-mvp-test-windows-portable.zip
```

发布前需要确认：

- 包内包含 `拼豆图纸转换工具.exe`。
- 包内包含 `README-请先看我.txt`。
- 包内包含 `_internal/apps/web/dist/index.html`。
- 包内包含 `_internal/data/palettes/mard-coco.v1.json`。
- 包内包含 RapidOCR `.onnx` 模型文件。
- 包内不包含 `.data`、`.venv`、`node_modules`、样例图目录、缓存或 `__pycache__`。

## 已知限制

- 当前主要面向规则网格图纸。
- 大面积水印、低清、拍歪或花体数字仍可能产生较多校对项。
- 当前版本优先保证无水印和轻水印图纸的基础转换流程。
- 当前仍是浏览器界面的本地工具，后续可演进为独立桌面软件界面。
