# 拼豆图纸标准转换器 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个完全本地运行的网页应用，将带可读 `MARD` 色号的规则网格图片半自动转换为可校对、可保存、可导出的 `COCO` 图纸项目。

**Architecture:** Python `FastAPI` 服务负责项目存储、色号映射、OpenCV 网格/取色处理、RapidOCR 文字识别和图纸导出；React + TypeScript 单页应用负责上传、左右对照校对、疑点确认和下载。识别结果先落到结构化 `.beadproject` 项目模型，界面和导出均消费同一模型，为后续画笔编辑功能保留基础。

**Tech Stack:** Python 3.10, FastAPI, Pydantic, Pillow, NumPy, OpenCV, RapidOCR + ONNX Runtime, pytest; Node 24, React, TypeScript, Vite, Vitest, Testing Library, SVG grid rendering.

---

## 0. 计划边界与技术决策

本计划覆盖一个完整但受控的 MVP：

- 输入为 `JPG`、`PNG`、`WebP` 规则电子网格图；未标标准时默认 `MARD`。
- 来源和目标首版仅开放 `MARD -> COCO`。
- OCR 是强证据，格子底色和本图重复色块是辅助证据；颜色容许偏差但不得静默替代存在冲突的 OCR。
- 用户可以确认映射或修正单格，并导出清单、干净重绘图、叠加检查图、可重开项目。
- 用户收集的原图与色卡图片作为本地参考资产，不提交到版本库；仓库只保存经人工核对的映射数据与自行生成的测试图片。
- 不实现实物照片、不带色号像素画、Excel、云端或多品牌界面。

选型依据：

- FastAPI 官方支持 `UploadFile`、静态文件服务和 `TestClient`，适合本机 API 与前端产物统一托管。
- OpenCV 可在本地执行网格线投影与形态学检测，无需远程服务。
- RapidOCR 的 Python 调用路径提供本地 OCR 引擎，避免要求用户单独安装系统级 Tesseract；在正式采用前通过样例可行性检查门槛验证微小英文数字色号识别效果。
- React + SVG 对当前最多数千格的校对视图足够，且比只输出位图更适合后续点击改格子。

参考文档：

- FastAPI: <https://fastapi.tiangolo.com/tutorial/request-files/>
- FastAPI testing: <https://fastapi.tiangolo.com/tutorial/testing/>
- Vite React setup: <https://vite.dev/guide/>
- RapidOCR: <https://rapidai.github.io/RapidOCRDocs/>

from enum import Enum
from pydantic import BaseModel, Field


class CellStatus(str, Enum):
    confirmed = "confirmed"
    review_required = "review-required"
    empty = "empty"


class RGB(BaseModel):
    r: int = Field(ge=0, le=255)
    g: int = Field(ge=0, le=255)
    b: int = Field(ge=0, le=255)


class GridGeometry(BaseModel):
    rows: int
    columns: int
    bounds: list[int]
    x_lines: list[int]
    y_lines: list[int]


class OcrCandidate(BaseModel):
    text: str
    normalized_code: str | None
    confidence: float


class Cell(BaseModel):
    row: int
    column: int
    sampled_color: RGB | None = None
    ocr_candidates: list[OcrCandidate] = Field(default_factory=list)
    detected_source_code: str | None = None
    confirmed_source_code: str | None = None
    target_code: str | None = None
    confidence: float = 0
    status: CellStatus = CellStatus.review_required
    issue_reasons: list[str] = Field(default_factory=list)


class MappingDecision(BaseModel):
    source_code: str
    target_code: str | None
    origin: str
    confidence: float


class BeadProject(BaseModel):
    format_version: int = 1
    id: str
    name: str
    source_image_name: str
    source_standard: str
    target_standard: str
    palette_version: str
    grid: GridGeometry
    mappings: list[MappingDecision]
    cells: list[Cell]
    export_history: list[str] = Field(default_factory=list)
    source_attribution: str | None = None

- [ ] **Step 4: 实现 JSON 项目存储与重新打开**

```python
class ProjectStore:
    def __init__(self, root: Path) -> None:
        self.root = root

    def save(self, project: BeadProject) -> None:
        folder = self.root / project.id
        folder.mkdir(parents=True, exist_ok=True)
        (folder / "project.json").write_text(
            project.model_dump_json(indent=2),
            encoding="utf-8",
        )

    def load(self, project_id: str) -> BeadProject:
        payload = (self.root / project_id / "project.json").read_text(encoding="utf-8")
        return BeadProject.model_validate_json(payload)
```

- [ ] **Step 3: 实现网格检测**

`detect_grid(image: PIL.Image.Image) -> GridGeometry` 的算法顺序固定如下：

```text
PIL -> grayscale ndarray
-> adaptive threshold invert
-> horizontal/vertical morphology kernels isolate long lines
-> projection peaks group near-adjacent pixels into line centers
-> validate near-regular spacing and minimum 2 x 2 cells
-> return rows, columns, bounds, x_lines, y_lines
```

公开错误类型：

```python
class GridNotFoundError(ValueError):
    pass
```

检测规则必须拒绝行列间距方差超过中位格宽 `15%` 的图片，避免普通插画进入误转换流程。
