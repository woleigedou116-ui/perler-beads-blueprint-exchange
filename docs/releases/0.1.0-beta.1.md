# 0.1.0-beta.1 测试版

发布日期：2026-05-31

这是拼豆图纸标准转换工具的第一个本地测试版，目标是先验证图片图纸的 `MARD -> COCO` 转换、人工校对和导出流程。当前版本适合在本机试用和继续收集样例，不建议当作正式发行版给完全不了解项目的人直接安装。

## 支持内容

- 上传常见图片格式的规则网格拼豆图纸。
- 自动识别格子、读取来源色号，并按本地 `MARD -> COCO` 对照表转换。
- 在左右预览中缩放、拖动、定位疑点格。
- 按组校对待确认格子，支持近似色号和完整目标色号表选择。
- 单格或矩形框选标记为非拼豆，用于处理水印、统计表和其他非图纸区域。
- 查看本图用到色号或全部色号，并按名称、数量和顺序切换。
- 保存并重新打开 `.beadproject` 项目文件，包含非拼豆状态和校对状态。
- 导出 `mapping.csv`、`clean.png`、`overlay.png` 和 `.beadproject`。

## 启动方式

首次准备环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
cd apps\web
npm install
npm run build
cd ..\..
```

启动本地服务：

```powershell
.\.venv\Scripts\python scripts\dev.py
```

浏览器打开：

```text
http://localhost:8765
```

## 本地数据与隐私

图片、项目文件和导出内容只由本机服务处理。项目运行数据默认写入 `.data/projects`，不会包含在测试版压缩包里。

## 已知限制

- 目前主要覆盖 `MARD -> COCO`，其他标准还没有正式实现。
- Excel 输入还没有接入。
- OCR 对水印、低清、花体数字或拍摄畸变仍可能误判，需要人工校对。
- 水印和非图纸区域当前采用识别后手动标记，识别前裁剪、多区域拼接、多边形排除属于后续功能。
- 测试版仍按本地开发服务运行，还不是一键安装的桌面应用。
