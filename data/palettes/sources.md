# 色号数据来源

## `mard-coco.v1`

- 录入日期：2026-05-26
- 来源：用户本地提供的 `标准对应转换/mard和coco/` 两张对照图片。
- 首批范围：覆盖首张样例图出现的色号，并加入样例中常见边框色 `H7`。
- 核对方式：逐行阅读参考图中的 `MARD` 与 `COCO` 色号对，人工录入并运行唯一性校验。
- 2026-05-30：根据 `拼豆色卡对照_1` 重新抽取 `sourceRgb` 与
  `targetRgb` 的屏幕近似值，修正若干红色、棕色、灰黑色映射被误采为
  近白色的问题；未改变 `MARD -> COCO` 色号对应关系。

`sourceRgb` 与 `targetRgb` 是根据屏幕参考图片整理的显示近似值，仅用于界面预览、图纸重绘和图像识别辅助排序；它们不是实体拼豆的测色数据。后续在导入更多样例或获得官方色卡时，新增版本而不是静默改写既有项目使用的版本。
