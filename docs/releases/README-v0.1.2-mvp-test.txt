拼豆图纸转换工具 v0.1.2-mvp-test

这是一个本地运行的 MVP 测试版工具，用来把带 MARD 色号的规则网格图纸转换成可校对、可导出的 COCO 图纸项目。

使用方式：

1. 解压整个 zip 文件。
2. 打开解压后的文件夹。
3. 双击「拼豆图纸转换工具.exe」。
4. 等待浏览器自动打开。
5. 上传图纸图片，完成识别、校对和导出。

注意事项：

- 请不要只复制 exe 单独运行。
- 需要保留同一文件夹里的 _internal 目录。
- 第一次启动或第一次识别可能较慢。
- 这是测试版，不是正式安装器。
- 图片和项目数据都在本机处理，不会上传到远程服务。

本版本主要变化：

- 修复 COCO 重绘预览中选中格框形状异常的问题。
- 优化滚轮缩放后的预览状态提交。
- 补充阶段性交接文档，方便后续继续开发。

如果浏览器没有自动打开，可以查看启动窗口里的本地地址，通常类似：

http://127.0.0.1:8765/
