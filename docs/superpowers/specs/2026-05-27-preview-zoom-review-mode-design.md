# 图纸预览缩放与全屏校对增强设计

## 1. 问题与目标

当前工作台可以并排查看原图叠加结果与 `COCO` 重绘结果，但对于
`40 x 63`、`50 x 50` 等真实图纸，两张图被压缩在固定卡片范围内，
用户难以看清单格文字、橙色待确认标记和目标色号。

本轮增强的目标是让用户在校对过程中能放大查看局部细节，并始终
保持来源图与目标图位于同一空间位置，减少反复寻找对应格子的成本。

## 2. 已选方案

采用用户确认的组合方案：

- 默认工作台继续显示左右双图对照。
- 两侧视图共享缩放比例和查看位置；操作任意一侧，另一侧同步变化。
- 增加全屏查看入口，在需要细查时扩大中间工作区，同时保留校对能力。

不采用“只显示一张图、在来源和目标间切换”的默认布局，因为转换校对
的核心动作是并排比较；频繁切换会增加记忆和定位负担。

## 3. 默认对照视图

### 3.1 预览工具栏

中间工作区顶部增加统一工具栏：

- `-` 与 `+`：按固定步长缩小或放大两张图。
- 当前比例展示，例如 `100%`、`150%`、`200%`。
- `适应窗口`：将两张完整图重新缩放到当前预览范围，并重置平移位置。
- `全屏查看`：进入扩大后的校对布局。

首版缩放设置采用可预测的固定上下限，避免图纸无限缩放后无法找回位置。

### 3.2 同步缩放与平移

- 初次加载图纸时使用适应窗口状态，完整图纸可见。
- 用户通过工具栏或在画布上滚轮缩放时，两侧使用同一个缩放比例。
- 图纸放大后，用户按住并拖动画布进行平移；两侧同步移动。
- 缩放以当前画布中心为优先锚点；首版不要求复杂的鼠标点位缩放。
- `适应窗口` 可随时恢复全图视角。

来源叠加视图继续使用原图作为底图并显示待确认标记；目标视图继续
渲染 `COCO` 重绘结果。同步操作只改变展示位置，不修改识别或项目数据。

## 4. 全屏查看模式

点击 `全屏查看` 后，工作台进入专门的校对布局：

- 隐藏上传与参数侧栏，为双图画布腾出横向空间。
- 双图仍保持并排、同步缩放与同步拖动。
- 校对列表保留为较窄侧栏，用户仍可确认映射或进入单格修改。
- 工具栏保留待确认数量、缩放控制、适应窗口和 `退出全屏`。
- 支持按 `Esc` 退出全屏查看。

此处的“全屏”是应用内占满浏览器内容区域的校对模式，不调用浏览器
原生全屏权限，避免额外提示和平台差异。

## 5. 状态与组件边界

`WorkbenchPage` 持有对照查看的共享交互状态：

- `zoom`：两侧共同使用的缩放级别。
- `pan`：两侧共同使用的横纵偏移。
- `isReviewFullscreen`：是否处于扩展校对布局。

新增一个负责双图协调的预览区域组件，或将协调逻辑集中在现有
工作台层；单个 `GridPreview` 只负责绘制自身内容并接受统一变换，
不各自保存独立缩放状态。这样可以确保左右视图不会走散。

项目模型、后端 API、图像识别算法和导出格式不因本轮交互增强而变化。

## 6. 异常与可用性约束

- 打开仅包含项目数据而没有当前上传预览 URL 的场景，来源侧继续使用
  已有回退网格预览，并参与同步缩放。
- 当缩放回到适应窗口状态时，平移归零，避免画布停在屏幕外。
- 拖动只在图纸画布区域生效，不影响点击待确认格子和校对按钮。
- 预览工具应显示当前模式和缩放比例，让用户能理解画布为何只显示局部。

## 7. 测试与验收

自动化测试覆盖：

- 工具栏能调高/调低共享缩放比例，并将变换同时应用到两侧视图。
- `适应窗口` 能重置放大和平移状态。
- 全屏查看模式能隐藏上传侧栏、保留校对区并可退出。
- 原图叠加标记在引入缩放容器后仍存在且可选中。

人工验收使用现有六张本地样例，重点检查：

- `40 x 63` 与 `50 x 50` 图纸放大后能辨认格子及标记。
- 拖动任意一侧时，原图与 `COCO` 视图保持同一区域对照。
- 全屏查看下仍能处理待确认项，退出后项目状态不丢失。

## 8. 本轮不包含

- 图纸格子的画笔编辑、涂色、擦除或批量框选编辑。
- 小地图导航、自动跳转下一个待确认格或键盘校对快捷键体系。
- 浏览器原生全屏模式。
- 对识别结果、色卡数据或导出图像生成逻辑的调整。
