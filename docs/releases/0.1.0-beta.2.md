# 0.1.0-beta.2 小白测试版

发布日期：2026-05-31

这个版本在 `0.1.0-beta.1` 的基础上增加 Windows 便携 exe 包。目标是让非开发用户解压后双击启动，不需要安装 Python、Node.js 或 npm。

## 新增内容

- 新增 `拼豆图纸转换工具.exe` 启动入口。
- 双击 exe 后会启动本地服务并自动打开浏览器。
- 如果 `8765` 端口被占用，会自动选择一个可用端口。
- 打包后的色号表、前端页面和运行数据目录使用便携包路径，不再依赖源码目录。
- 包内附带 `README-请先看我.txt`，说明启动、关闭和数据位置。

## 使用方式

1. 解压 `perler-beads-blueprint-exchange-0.1.0-beta.2-windows-portable.zip`。
2. 打开解压后的文件夹。
3. 双击 `拼豆图纸转换工具.exe`。
4. 浏览器自动打开后开始上传图纸。

## 已知限制

- 这是便携测试版，不是正式安装器。
- 需要保留整个文件夹，不能只复制 exe 单独运行。
- 第一次启动可能较慢。
- 自制 exe 可能被部分杀毒软件提示风险，需要后续签名或正式发布流程改善。
- OCR 识别准确率仍以人工校对兜底。
