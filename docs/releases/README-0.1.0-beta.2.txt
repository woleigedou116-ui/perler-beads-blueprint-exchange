拼豆图纸转换工具 0.1.0-beta.2 测试版

使用方法：

1. 解压整个文件夹。
2. 双击“拼豆图纸转换工具.exe”。
3. 等待几秒，浏览器会自动打开。
4. 如果浏览器没有自动打开，请看黑色窗口里的地址，通常是：
   http://127.0.0.1:8765/

注意事项：

- 请不要只把 exe 单独复制出去运行，需要保留同一个文件夹里的其他文件。
- 运行时会打开一个黑色窗口，这是本地服务窗口。关闭这个窗口，软件也会停止。
- 图片和项目文件只在本机处理，不会上传到远程服务。
- 本地项目缓存会保存在当前文件夹下的 .data 目录。
- 这是测试版，OCR 对水印、低清、拍歪、花体数字仍可能误判，请以人工校对结果为准。

当前主要支持：

- 图片图纸识别。
- MARD 到 COCO 色号转换。
- 人工校对。
- 单格/框选标记非拼豆。
- 保存和重新打开 .beadproject。
- 导出 CSV、干净图、叠加图和项目文件。
